# BarkaPay × TotalEnergies

Présentation commerciale interactive (une page HTML) du projet **BarkaPay**, une solution de paiement pour les stations-service au Burkina Faso, proposée à TotalEnergies.

## Sections

Contexte des stations burkinabè · parcours de paiement en 6 étapes · bénéfices pour Total · déploiement (Ouagadougou puis Bobo-Dioulasso) · taille de marché · sources de revenus · feuille de route (MVP en 3 mois) · application et comptes par station · circulation de l'argent · stack technique.

## Lancer

Ouvrir `index.html` dans un navigateur (icônes chargées depuis cdnjs, polices Google Fonts).
